# EZ VPN Lego

[Русский](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md)

Свой VPN на своих серверах. Установил, привязал Telegram, выдал доступ.
Без обязательной панели и привязки к чужому облаку.

Сейчас опубликован одиночный режим: один VPS, VLESS REALITY Vision,
управление через Telegram. В разработке модульный режим: прямое подключение
или каскад с любым количеством входных и выходных узлов.

## Что уже работает

- установка на чистую Ubuntu Server 24.04, `amd64` и `arm64`;
- Telegram-бот с одноразовой привязкой владельца;
- отдельные доступы для людей и устройств;
- проверка конфигурации перед применением и откат при ошибке;
- ежедневные резервные копии и подписанные обновления;
- работа VPN при недоступном боте или контроле.

## Установить опубликованную версию

Нужны чистый VPS и токен своего бота от [@BotFather](https://t.me/BotFather).
На сервере выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/steam9steam-prog/ez-vpn-lego/main/install.sh | sudo bash
```

Установщик попросит токен без отображения ввода. Затем покажет одноразовую
ссылку и QR для привязки Telegram. Ссылка действует 15 минут.

Свой домен для этого режима не нужен. Нужен свободный TCP 443, доступный
из интернета. На сервере не должно быть чужих сервисов на этом порту.

## Модульный режим в разработке

Две схемы:

```text
Пользователь → VPN-нода → Интернет
Пользователь → Входная нода → Выходная нода → Интернет
```

География любая. Контрол можно описать на входе, на выходе или отдельно.
Количество узлов в модели не ограничено фиксированным числом.

В этой ветке уже есть планировщик, генератор Xray-конфигураций и локальный
инструмент подготовки установки. Он сохраняет ключи между изменениями,
готовит индивидуальные подписки и проверяет DNS. Планировщик доступен
через общий API. Каталог профилей можно посмотреть и в Telegram.

Автоматическое подключение удалённых узлов и управление всем каскадом
через Telegram ещё не готовы. Публичный установщик пока ставит одиночную
версию. Генерация файлов не означает, что они применены на серверах.

## Обслуживание одиночной установки

```bash
sudo -u ezvpn bash -c 'set -a; source /etc/ez-vpn-lego/ezvpn.env; set +a; lego-vpnctl status'
sudo ez-vpn-lego backup
sudo ez-vpn-lego update
sudo ez-vpn-lego restore /path/to/backup.tar.gz
```

Копия содержит ключи и настройки. Храните её как пароль и выносите с VPS
в защищённое хранилище. Текущий архив сам по себе не зашифрован.

Подробнее: [обслуживание](docs/operations.md), [модель угроз](docs/threat-model.md),
[API](api/openapi.yaml).

## Разработка

```bash
make generate-check
make fmt vet test-race build
```

Для проверки настоящего прямого подключения и каскада на loopback:

```bash
XRAY_BINARY=/absolute/path/to/xray go test -race ./drivers/xray/topology -v
```

Установщик проверяется на одноразовой Ubuntu VM:

```bash
./tests/e2e/ubuntu-vm.sh
```
